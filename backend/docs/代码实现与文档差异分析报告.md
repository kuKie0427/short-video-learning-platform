# 代码实现与文档差异分析报告

## 一、执行摘要

本报告对比分析了项目实际代码实现与设计文档的差异，主要涵盖以下三个方面：

1. **API接口差异**：对比API设计文档与实际实现的接口路径、参数、响应格式
2. **数据库模型差异**：对比数据库设计文档与实际SQLAlchemy模型的字段、约束、索引
3. **系统架构差异**：对比系统架构设计文档与实际服务实现

**总体情况**：
- ✅ 大部分核心功能已实现
- ⚠️ 部分接口路径与文档不一致
- ⚠️ 部分数据库字段与文档有差异
- ⚠️ 部分文档中定义的接口未实现
- ⚠️ 部分实际实现的接口未在文档中记录

## 二、API接口差异分析

### 2.1 认证相关接口（Auth服务）

#### ✅ 已实现且与文档一致
- `POST /api/auth/send-code` - 发送验证码（文档：`/api/auth/send_code`）
- `POST /api/auth/login` - 手机号验证码登录（文档：`/api/auth/login_by_phone`）
- `GET /api/auth/profile` - 获取当前用户信息（文档：`/api/user/me`）
- `PUT /api/auth/profile` - 更新用户资料

#### ⚠️ 路径差异
| 文档路径 | 实际路径 | 说明 |
|---------|---------|------|
| `POST /api/auth/send_code` | `POST /api/auth/send-code` | 使用连字符而非下划线 |
| `POST /api/auth/login_by_phone` | `POST /api/auth/login` | 简化路径 |
| `GET /api/user/me` | `GET /api/auth/profile` | 路径不同，功能相同 |

#### ➕ 实际实现但文档未记录
- `POST /api/auth/refresh` - 刷新访问令牌

#### ⚠️ 响应格式差异
- **登录接口响应**：实际返回包含 `token`、`token_type`、`expires_in`、`user` 对象，与文档基本一致，但字段名略有不同（文档中 `token`，实际也是 `token`）

### 2.2 内容与推荐相关接口（Content服务）

#### ⚠️ 路径差异

### 2.3 互动接口（Content服务）

- `POST /api/interaction/favorite` - 收藏（文档：`POST /api/video/{video_id}/favorite`）
- `POST /api/interaction/comment` - 发表评论
- `GET /api/interaction/video/{video_id}/comments` - 评论列表（文档：`GET /api/video/{video_id}/comments`）

#### ⚠️ 路径差异
| 文档路径 | 实际路径 | 说明 |
|---------|---------|------|
| `POST /api/video/{video_id}/like` | `POST /api/interaction/like` | 使用统一交互接口，通过请求体传递video_id |
| `POST /api/video/{video_id}/favorite` | `POST /api/interaction/favorite` | 同上 |
| `GET /api/video/{video_id}/comments` | `GET /api/interaction/video/{video_id}/comments` | 路径前缀不同 |

#### ⚠️ 请求参数差异
- **点赞/收藏接口**：文档中路径参数 `video_id`，实际实现使用请求体传递 `video_id`
- **点赞接口响应**：文档中 `action` 参数（like/unlike），实际实现为切换操作（toggle）

#### ➕ 实际实现但文档未记录

- `GET /api/interaction/user/likes` - 获取用户点赞的视频

### 2.4 上传相关接口（Upload服务）

#### ✅ 已实现且与文档一致
- `POST /api/upload/init` - 初始化上传任务
- `PUT /api/upload/chunk` - 分片上传（文档：`PUT {upload_url}`）
- `POST /api/upload/complete` - 完成上传并发起转码

#### ⚠️ 路径差异
| 文档路径 | 实际路径 | 说明 |
|---------|---------|------|
| `PUT {upload_url}` | `PUT /api/upload/chunk` | 使用固定路径，通过请求头传递upload_id和chunk_index |

#### ⚠️ 请求参数差异
- **分片上传**：文档中通过Query参数传递 `upload_id` 和 `chunk_index`，实际实现通过请求头传递
- **初始化上传响应**：文档中返回 `upload_url` 为完整URL，实际返回相对路径 `"upload/chunk"`

#### ➕ 实际实现但文档未记录
- `POST /api/upload/image` - 上传图片（头像等）

#### ❌ 文档中定义但未实现

## 三、数据库模型差异分析

### 3.1 用户表（users）

#### ✅ 字段一致
- `id`, `phone`, `nickname`, `avatar_url`, `bio`, `language`, `roles`, `created_at`, `updated_at`

#### ➕ 实际实现但文档未记录
- `gender` - 性别（String(10), default='male'）
- `location` - 位置（String(100)）
- `school` - 学校（String(100)）

#### ⚠️ 字段类型差异
- `roles`：文档中为 `VARCHAR(50)[]`，实际为 `ARRAY(String(50))`（PostgreSQL数组类型，一致）

### 3.2 视频表（videos）

#### ✅ 字段一致
- 所有核心字段与文档一致

#### ⚠️ 索引差异
- 文档中定义了 `idx_videos_tags` (GIN索引)，实际模型中未找到此索引定义
- 文档中定义了 `idx_videos_parent_video_id` 和 `idx_videos_course_id`，实际模型中未找到这些索引定义

### 3.3 学习记录表（learn_records）

#### ⚠️ 字段差异

### 3.4 评论表（comments）

#### ⚠️ 索引差异

### 3.6 收藏表（favorites）

### 3.7 上传任务表（upload_tasks）

#### ✅ 字段一致

- 文档中定义状态为 `uploading/uploaded/transcoding/finished/failed`

## 四、系统架构差异分析

### 4.1 服务架构

#### ✅ 服务列表一致
- Auth服务 (8001)
- Content服务 (8002)
- Upload服务 (8003)
- Split服务 (8004)
- Course服务 (8005)
- Search服务 (8006)

#### ⚠️ 技术栈差异

### 4.3 API网关

#### ✅ 实现一致
- 使用 Nginx 作为 API 网关
- 路由配置与文档描述基本一致

#### ⚠️ 路由差异
- 部分接口路径前缀与文档不一致（如 `/api/feed` vs `/api/video`）

## 六、总结

### 6.1 差异统计

| 类别 | 差异数量 | 严重程度 |
|------|---------|---------|
| API接口路径差异 | 15+ | 中等 |
| API接口缺失 | 2 | 低 |
| API接口未文档化 | 10+ | 中等 |
| 数据库字段差异 | 5 | 低 |
| 数据库索引缺失 | 8+ | 高 |

### 6.2 主要问题

1. **接口路径不一致**：部分接口路径与文档定义不一致，可能影响前端集成
2. **索引缺失**：多个表缺少必要的索引，可能影响查询性能
3. **文档不完整**：部分实际实现的接口和功能未在文档中记录
4. **技术栈描述不准确**：架构文档中描述的技术栈与实际实现不一致

1. **立即修复**（高优先级）
   - 补充数据库索引
   - 统一接口路径命名
   - 更新架构文档中的技术栈描述

2. **近期修复**（中优先级）
   - 补充缺失的接口文档
   - 实现文档中定义但未实现的接口

3. **长期优化**（低优先级）
