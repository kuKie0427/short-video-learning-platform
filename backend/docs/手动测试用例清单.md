# 手动测试用例清单（人工冒烟 / 探索性 / 视觉验收）

> 配套《测试设计文档》：自动化用例（315 例 pytest + 10 例 Vitest + 6 例 Playwright）负责**回归**，
> 本清单负责自动化判不了的三类场景：**视觉体验、探索性发现、上线人工确认**。
> 手动用例不跑 CI，按需执行，执行结果记录在文末表格。

---

## 1. 自动化 / 手动分工原则

| 维度 | 自动化（315 例 + 前端 + E2E） | 手动（本清单） |
| --- | --- | --- |
| 目的 | 回归：证明"改动没破坏已有行为" | 发现：找自动化想不到的缺陷 |
| 断言对象 | 状态码 / 响应体 / 数据库最终态 | 视觉 / 交互手感 / 业务直觉 |
| 执行时机 | 每次提交（CI 全量 ~18s） | 发布前 / 新功能首测 / 定期抽查 |
| 覆盖范围 | 接口逻辑、参数矩阵、链路 | UI 布局、动效、弱网、异常操作 |

**判断标准**：一条用例若"机器能稳定断言"，归自动化；若"需要人眼/手感判断"，归手动。
典型例子：`feed/recommend` 返回 200 且字段完整 → 自动化；推荐流"看起来是不是真的个性化" → 手动。

## 2. 发布前人工冒烟清单（Release Smoke）

> 上线前必须人工过一遍，约 5 分钟。自动化冒烟测"接口通不通"，人工冒烟测"人用起来顺不顺"。

| # | 场景 | 操作步骤 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| S1 | 注册登录 | 新手机号发验证码 → 登录 → 自动注册 | 进入首页，无报错 | ☐ |
| S2 | 已有用户登录 | 老账号验证码登录 | 秒进首页，token 有效 | ☐ |
| S3 | 视频流浏览 | 首页下滑 10 条视频 | 视频能播、封面加载、点赞数显示 | ☐ |
| S4 | 视频播放 | 点开任意视频 → 播放/暂停/进度拖动 | 流畅，无黑屏/卡死 | ☐ |
| S5 | 互动 | 点赞 → 取消点赞 → 评论 → 收藏 | 数字即时变化，无整页刷新 | ☐ |

| S7 | 搜索 | 搜"数学"→ 切 tag/author 类型 | 结果正确，空结果有友好提示 | ☐ |
| S8 | 上传 | 上传一个短视频 → 进度 → 成功 | 出现在个人页/首页 | ☐ |
| S9 | 智能分割 | 传长视频 → 分割 → 片段可发布 | 分割结果合理，无崩溃 | ☐ |
| S10 | 个人页 | 编辑昵称/头像 → 刷新 | 修改生效且持久 | ☐ |
| S11 | 课程页 | 打开课程 → 播放课内视频 | 课程结构正确 | ☐ |
| S12 | 消息 | 收到评论/点赞通知 → 打开消息页 | 通知列表正确 | ☐ |

## 3. 探索性测试清单（Exploratory Charter）

> 无脚本、有主题的探索。每条 10-15 分钟，目标不是"确认能用"，而是"找出自动化没想到的问题"。
> 建议用**截图 + 复现步骤**记录发现，筛出可自动化用例后沉淀进 `backend/tests/`。

| # | 探索主题（Charter） | 探索提示 | 重点怀疑 |
| --- | --- | --- | --- |
| E1 | 弱网/慢速 | 用 DevTools 限速 3G，走完登录→刷流→上传 | 超时提示、加载态、重复提交 |
| E2 | 快速连点 | 点赞/评论/关注按钮快速连点 10 次 | 幂等性、计数漂移、重复请求 |
| E3 | 异常输入 | 搜索框输入表情、超长、SQL/HTML 片段、空格 | 注入、长度截断、报错友好度 |
| E4 | 上传边界 | 超大文件、0 字节文件、非视频扩展名、文件名含中文/空格 | 错误提示、脏数据残留 |
| E5 | 分割边界 | 极短视频、纯黑帧视频、无语音视频、只含静音 | 分割是否优雅降级、是否崩溃 |
| E6 | 多端适配 | 手机宽度（375px）/平板/窄窗口分别走主流程 | 布局溢出、按钮不可点 |
| E7 | 并发冲突 | 两个标签页同时登录/同时点赞同一视频 | 会话互踢、数据一致性 |
| E8 | 刷新/回退 | 播放中刷新、上传中回退、搜索后回退 | 状态丢失、重复提交 |

## 4. 视觉验收清单（Visual Acceptance）

> 机器断言不了"好不好看"，由人确认。建议按浏览器截图对比。

| # | 检查项 | 验收标准 | 结果 |
| --- | --- | --- | --- |
| V1 | 首页信息密度 | 卡片间距统一、无挤压/留白异常 | ☐ |
| V2 | 视频封面比例 | 封面无拉伸变形、懒加载无闪白 | ☐ |
| V3 | 播放器控件 | 进度条/音量/全屏图标清晰可点 | ☐ |
| V4 | 空状态 | 空搜索/空关注流/空消息有设计过的占位 | ☐ |
| V5 | 加载状态 | 骨架屏/loading 不跳动、不闪烁 | ☐ |
| V6 | 错误提示 | 表单错误红字、toast 位置不挡内容 | ☐ |
| V7 | 动效流畅 | 点赞动画、页面切换无掉帧 | ☐ |
| V8 | 深色/浅色一致性 | 无刺眼对比、无未适配区域 | ☐ |

## 6. 用例体系小结（可复述）

> "我的用例体系是**自动化回归 + 手动发现**双层：315 条 pytest 管接口回归（十几秒全量进 CI）、6 条 Playwright 管主链路冒烟、10 条 Vitest 管前端组件；**手动保留三类**：发布前 13 条人工冒烟（测人用起来顺不顺）、8 条探索性 Charter（找自动化想不到的问题）、8 条视觉验收（机器判不了好看不好看）。分工原则是：**机器能稳定断言的归自动化，需要人眼/手感判断的留手动**，两者合起来才是完整的用例设计。"
