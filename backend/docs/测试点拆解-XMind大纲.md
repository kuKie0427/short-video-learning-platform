# 测试点拆解大纲（XMind 导入用）

> 使用：新建 XMind → 导入 Markdown/粘贴本文件大纲 → 每个测试点后括号内是设计方法标签（等=等价类 / 边=边界值 / 判=判定表 / 场=场景法 / 态=状态迁移 / 错=错误推测 / 安=安全专项）。
> 拆解维度口述：**服务 → 功能模块 → 测试点 → 方法标签 → 对应用例编号**（编号见《手工测试用例-正式版》与 pytest 套件）。

- 短视频学习平台（7 服务 · 56 接口）
  - Auth 认证服务
    - 验证码下发
      - 手机号位数 9/10/11/12（边）
      - 手机号缺失/空/非数字（等·无效）
      - 重复下发频率（错）
    - 验证码登录
      - 正确码×有效手机号（等·有效）
      - 错误码/过期码（等·无效）
      - 新用户自动注册 vs 老用户（判）
    - Token 边界
      - 无/伪造/过期/缺 sub 凭证矩阵（安·四参数）
      - access 过期→refresh 换发（态）
    - 用户资料
      - 昵称/头像编辑持久化（场）
      - UUID 直通建号幂等（态）
  - Upload 上传服务
    - 初始化 init
      - 参数校验（等）
      - 返回契约：chunk_size=5MB（边·客户端契约）
    - 分片上传 chunk
      - 正常分片序列（场）
      - 分片重复→覆盖不追加（态·幂等）
      - 分片缺失→complete 拒绝且回滚（错）
      - 非法索引/乱序（错）
    - 合并 complete
      - 200 响应必须含 video_id/status/file_url（场·BUG-004 回归）
      - 落库一致性 SQL 校验（场）
      - 长短视频自动分类（判）
      - 并发 complete 唯一约束兜底（错）
    - 文件校验
      - FFprobe 格式校验（等）
      - 0 字节/非视频/超大/中文名（错）
      - 无效 base64 → 422 非 500（错·BUG-014）
    - 越权
      - 他人 upload_id 操作 → 403（安）
  - Split 切分服务
    - 智能切分链路
      - 提音频→ASR→GLM 分析→切分（场·主成功）
      - 极短/纯黑帧/无语音视频（错）
    - 降级路径
      - 无 GLM Key → 60s 等长切分（判）
      - AI 依赖缺失 → 显式报错不崩溃（判）
    - 任务管理
      - 任务列表含 video_id、刷新可恢复（场·BUG-012）
      - 用户隔离：B 不可见 A 任务（安）
    - confirm 确认
      - 外键映射正确（场·BUG-008）
      - 外键不存在 → 400 非 500（错）
      - 非作者 confirm → 403（安）
  - Content 内容服务
    - 推荐流 recommend
      - 四策略混合输出（场）
      - 个性化差异人工确认（场·手动）
    - 热门流 hot
      - popularity 主导排序（边·BUG-010）
      - 高热旧 vs 冷启动新（判）
    - 互动
      - 点赞状态机 like/unlike 循环（态）
      - 计数与行数一致（态）
      - 连点幂等（错）
      - 评论树/收藏/关注（场）
    - 学习记录 learn
      - completion_rate 落库契约（场）
      - 鉴权规则与 upload 一致（安·BUG-006）
  - Search 搜索服务
    - 关键词
      - 长度 1/100/空/101（边）
      - 表情/HTML/注入载荷（错·安）
    - 通配符
      - % _ \ 字面量匹配（安·BUG-009）
    - 排序
      - hot 与 latest 序可区分（判·BUG-015）
      - tag/author 类型切换（等）
    - 建议
      - 前缀联想（场）
  - Course 课程服务
    - CRUD（场）
    - 视频-课程多对多关联（判）
    - 外键不存在 → 400（错）
    - 学习进度追踪（态）
  - Notification 通知服务
    - 公告/互动通知到达（场）
    - 已读状态（态）
  - 跨服务链路（E2E 冒烟）
    - 登录→浏览→搜索（场）
    - 上传→切分→发布（场）
    - 网关路由与静态直出（错·BUG-011 部署路径）
  - 非功能
    - 性能：4 读接口 Locust 基线（20/200 用户两轮）+ 网关整链路基线（Docker 全栈+Redis，20/200 两轮，200ms/1% 门禁）
    - 兼容：Chrome/Edge/Safari/375px
    - 视觉：V1-V8 清单
