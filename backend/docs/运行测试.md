## 安装测试依赖

### 方法1：使用pip安装（推荐）


或者只安装测试依赖：

```bash

```

### 方法2：使用conda（如果使用conda环境）


## 运行测试

### 0. 准备测试环境

```bash
cd backend

# 确保PostgreSQL运行
docker-compose up -d postgres

# 创建测试数据库
python scripts/create_test_db.py

# 验证测试环境
python scripts/test_connection.py
```

### 1. 运行所有测试

```bash
cd backend

# 运行所有测试
pytest tests/ -v

# 运行测试并生成覆盖率报告
pytest tests/ -v --cov=. --cov-report=html

# 查看覆盖率报告
open htmlcov/index.html
```

### 2. 运行特定类型的测试

```bash

pytest tests/unit/

# 只运行API测试

pytest tests/api/test_auth.py
```

### 3. 运行并查看详细输出

```bash
# 显示详细输出
pytest -v

# 显示最详细输出和print语句
pytest -vv -s
```

### 4. 生成覆盖率报告

```bash

start htmlcov/index.html
```

### 5. 运行特定测试


## 常见问题

### 1. ModuleNotFoundError: No module named 'pytest'

**解决方案**：安装pytest
```bash
pip install pytest
```

### 2. Redis连接错误

**说明**：测试已实现Redis fallback机制，当Redis不可用时自动使用内存存储。

**如果需要测试Redis功能**：
```bash
# 启动Redis
docker-compose up -d redis

# 验证Redis连接
docker exec -it short_video_redis redis-cli ping
```

### 3. 数据库连接错误

**说明**：测试使用独立的测试数据库（`short_video_platform_test`）。

**解决方案**：
```bash
# 1. 启动PostgreSQL
docker-compose up -d postgres

# 2. 创建测试数据库
python scripts/create_test_db.py

# 3. 测试连接
python scripts/test_connection.py

# 4. 如果仍有问题，检查配置
docker exec -it short_video_postgres psql -U app_user -l
```

**注意事项**：
- 测试使用 `127.0.0.1` 而不是 `localhost`（避免IPv6问题）
- 每个测试函数使用独立的数据库会话
- 测试后自动清理数据

### 4. 导入错误

**说明**：测试代码现在使用`common`模块，确保路径配置正确。

**解决方案**：
```bash
# 确保在backend目录下运行
cd backend

# 检查Python路径
python -c "import sys; print(sys.path)"

# 检查common模块是否可以导入
python -c "from common.models import User; print('OK')"

# 如果导入失败，检查backend目录结构
ls -la backend/common/
```

## 测试最佳实践

### 编写新测试
1. 使用 `conftest.py` 中的fixtures（`db`, `client`, `auth_headers`等）
2. 遵循AAA模式（Arrange-Act-Assert）
3. 使用有意义的测试名称
4. 测试边界条件和错误情况

### 测试数据管理
- 使用 `fixtures/sample_data.py` 创建测试数据
- 每个测试使用独立的数据库会话
- 避免测试之间的数据依赖

### 性能优化
- 使用 `pytest-xdist` 并行运行测试
- 合理使用 `scope` 参数（function/class/module/session）
- 避免不必要的数据库操作
