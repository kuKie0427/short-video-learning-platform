# 数据库本地部署指南

## 📋 前置要求

- **Docker Desktop**（Windows/Mac）或 **Docker + Docker Compose**（Linux）
- **Git**（用于克隆项目）

## 🚀 快速开始

### 1. 准备环境变量

```bash
# 复制环境变量模板
cp env.example .env
```

`.env` 文件已包含所有必需的数据库配置，无需修改即可使用。

### 2. 启动数据库服务

```bash
# 启动PostgreSQL、Redis和MinIO
docker-compose up -d

# 查看服务状态
docker-compose ps
```

### 3. 验证数据库连接

```bash
# 测试PostgreSQL连接
docker-compose exec postgres psql -U app_user -d short_video_platform -c "SELECT 1"

# 查看所有表（应该看到13张表）
docker-compose exec postgres psql -U app_user -d short_video_platform -c "\dt"
```

## 📊 数据库信息

### PostgreSQL

- **地址**: `localhost:5432`
- **数据库名**: `short_video_platform`
- **用户名**: `app_user`
- **密码**: `app_password_2025`

### Redis

- **地址**: `localhost:6379`
- **密码**: 无

### MinIO（对象存储）

- **API地址**: `http://localhost:9000`
- **控制台**: `http://localhost:9001`
- **用户名**: `minioadmin`
- **密码**: `minioadmin123`

## 🗄️ 数据库表结构

数据库会自动创建以下13张表：

1. `users` - 用户表
2. `videos` - 视频表
3. `learn_records` - 学习记录表
4. `comments` - 评论表
5. `likes` - 点赞表
6. `favorites` - 收藏表
7. `upload_tasks` - 上传任务表
8. `notifications` - 通知表
9. `long_videos` - 长视频表
10. `split_tasks` - 拆分任务表
11. `split_segments` - 拆分片段表
12. `courses` - 课程表
13. `course_videos` - 课程视频关联表

## 🔧 常用操作

### 查看数据库日志

```bash
docker-compose logs postgres
```

### 进入PostgreSQL命令行

```bash
docker-compose exec postgres psql -U app_user -d short_video_platform
```

### 执行SQL文件

```bash
docker-compose exec -T postgres psql -U app_user -d short_video_platform < your_script.sql
```

### 备份数据库

```bash
docker-compose exec postgres pg_dump -U app_user short_video_platform > backup_$(date +%Y%m%d).sql
```

### 恢复数据库

```bash
docker-compose exec -T postgres psql -U app_user short_video_platform < backup_20250101.sql
```

### 重置数据库（删除所有数据）

```bash
# 停止服务并删除数据卷
docker-compose down -v

# 重新启动（数据库会自动重新初始化）
docker-compose up -d
```

## 🐛 常见问题

### Q: 端口5432已被占用？

**A**: 修改 `docker-compose.yml` 中的端口映射：
```yaml
ports:
  - "5433:5432"  # 改为其他端口
```

### Q: 数据库连接失败？

**A**: 检查以下内容：
1. 服务是否运行：`docker-compose ps`
2. 查看日志：`docker-compose logs postgres`
3. 等待服务完全启动（首次启动需要几秒钟）

### Q: 表没有自动创建？

**A**: 
1. 检查 `database/init.sql` 文件是否存在
2. 查看PostgreSQL日志：`docker-compose logs postgres`
3. 手动执行初始化脚本：
   ```bash
   docker-compose exec -T postgres psql -U app_user -d short_video_platform < database/init.sql
   ```

### Q: 如何停止服务？

**A**: 
```bash
# 停止服务（保留数据）
docker-compose stop

# 停止并删除容器（保留数据）
docker-compose down

# 停止并删除所有数据
docker-compose down -v
```

## 📝 开发建议

1. **使用本地数据库开发**：每个开发者使用独立的本地数据库，避免数据冲突
2. **定期备份**：重要数据记得备份
3. **重置测试**：开发过程中可随时重置数据库进行测试
4. **查看日志**：遇到问题先查看日志：`docker-compose logs -f`
