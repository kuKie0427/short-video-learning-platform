# 短视频学习平台 - 前端需求文档 (Frontend Requirements Document)

**版本**: 1.1  
**更新日期**: 2025-12-25  
**状态**: 已实现 (Implemented) / 进行中

---

## 1. 项目概述 (Project Overview)

本项目是一个**移动端优先 (Mobile-First)** 的短视频学习平台 Web 应用（H5）。旨在利用碎片化时间，通过沉浸式的短视频流形式提供知识学习体验。核心特色包括类似 TikTok 的交互体验、高可靠性的断点续传上传机制以及基于心跳的学习进度追踪系统。

### 1.1 技术栈
- **核心框架**: React 18 + TypeScript
- **构建工具**: Vite
- **样式方案**: Tailwind CSS (移动端适配)
- **路由管理**: React Router v6
- **图标库**: Lucide React
- **HTTP 请求**: Axios (拦截器封装)
- **状态管理**: React Context API (Auth)

---

## 2. 信息架构 (Information Architecture)

### 2.1 导航结构
采用底部导航栏 (Bottom Navigation) 模式，包含 5 个核心 Tab：
1. **首页 (Home)**: 沉浸式视频流
2. **课程 (Courses)**: 发现与搜索 (增强)
3. **创作 (Upload)**: 视频上传与拆分 (核心功能)
4. **消息 (Inbox)**: 通知中心 (细化)
5. **我的 (Profile)**: 个人数据与学习概览

## 3. 功能模块详解 (Functional Requirements)

### 3.1 用户认证模块 (Authentication)
*   **登录 (Login)**
    *   支持手机号 + 验证码登录。
    *   **交互**: 获取验证码倒计时，输入框格式校验。
    *   **逻辑**: 登录成功后存储 JWT Token 至 LocalStorage，并更新全局 AuthContext。
    *   **重定向**: 支持 `redirect_url`，登录后自动跳转回触发登录的页面。
*   **路由守卫 (Route Guard)**
    *   实现 `ProtectedRoute` 组件。
    *   未登录用户访问 `/upload`, `/inbox`, `/profile` 时强制跳转至登录页。
*   **退出登录 (Logout)**
    *   个人中心提供退出按钮，清除本地 Token 并重置状态。

### 3.2 首页视频流 (Home Feed)
*   **交互体验**
    *   全屏垂直滚动，使用 CSS Scroll Snap 实现“一次滑一个”的效果。
    *   当前视图中心的视频自动播放，划出视图的视频自动暂停并重置。
*   **视频播放器**
    *   支持播放/暂停手势（点击屏幕）。
    *   底部显示进度条。
    *   **增强互动**:
        *   **侧边栏**: 展示头像（关注）、点赞、**收藏**（新增，独立于点赞）、评论、分享。
*   **评论区 (Comments)**
    *   **二级回复**: 支持楼中楼展示（主评论及子评论）。
    *   **交互**: 点击评论图标从底部弹出评论面板。

### 3.3 课程与搜索 (Courses & Search) - *增强*
*   **搜索功能**
    *   **联想词**: 输入关键词时实时展示联想推荐。
    *   **历史记录**: 展示用户的最近搜索历史，支持点击快速搜索和清除。
*   **筛选与过滤**
    *   支持按 **时长** (如: <5min, 5-15min) 筛选。
    *   支持按 **标签/分类** (如: 编程, 设计, 语言) 过滤课程列表。

### 3.4 创作中心 (Upload & Creation) - *核心*
*   **文件选择与校验**
    *   支持选择本地视频文件。
    *   **硬性规则**: 前端不再强制限制视频时长；可能由后端或审核策略进行限制。
*   **上传前预处理 (Pre-process)**
    *   **本地压缩**: 上传前调用本地压缩逻辑（如 ffmpeg.wasm 或类似库）减小文件体积。
    *   **封面选择**: 支持从视频中截取帧或上传自定义图片作为封面。
*   **高可靠分片上传 (VideoUploader)**
    *   **分片策略**: 将大文件切分为 2MB/片 (Chunk)。
    *   **断点续传**:
        *   使用 LocalStorage 记录 `upload_id` 和已完成的 `chunk_index`。
        *   页面刷新或中断后，自动跳过已上传分片。
    *   **重试机制**: 单个分片失败触发指数退避重试 (最多 3 次)。
    *   **UI 反馈**: 显示精确百分比进度和当前分片状态（预处理 -> 上传中 -> 转码中 -> 完成）。
*   **智能拆分设置**
    *   提供三种模式选择：全自动 (Auto)、混合模式 (Hybrid)、纯手动 (Manual)。

### 3.5 消息中心 (Inbox) - *细化*
*   **分类展示**
    *   **评论互动**: 收到的评论、点赞和回复。
    *   **系统通知**: 平台公告、活动通知。
    *   **审核通知**: 视频审核结果通知（若被驳回，需明确展示**驳回原因**）。

### 3.6 学习系统 (Learning System) - *核心*
*   **视频详情页**
    *   独立页面 `/video/:id` 用于专注学习。
*   **心跳机制 (Heartbeat)**
    *   **逻辑**: 视频播放期间，每 **10秒** 向后端发送一次心跳请求。
    *   **触发时机**: 定时器触发、暂停时触发、页面卸载时尝试触发。
    *   **数据**: 包含 `video_id`, `position` (当前秒数), `buffered` (缓冲进度), `playing` (状态)。
*   **完成反馈**
    *   **逻辑**: 当播放进度达到 **90%** 时，自动暂停视频。
    *   **弹窗交互**: 弹出模态框询问学习效果：
        *   ✅ **我已学会**: 标记状态为 `learned`。
        *   ⚠️ **需复习**: 标记状态为 `review_needed`（加入待复习列表）。

### 3.7 个人中心 (Profile)
*   **用户信息**
    *   展示头像、昵称、获赞/关注/粉丝数。
    *   **设置入口**: 增加设置页面入口，支持修改个人资料（头像、昵称）。
*   **学习数据看板 (UserProfileStats)**
    *   **统计卡片**: 展示“累计学习时长”和“已修完课程数”。
    *   **待复习列表 (Review List)**:
        *   横向滚动列表 (Horizontal ScrollView)。
        *   仅展示状态为 `review_needed` 的视频记录。
        *   点击卡片跳转至视频详情页进行复习。
    *   **浏览历史**: 增加浏览历史列表入口，方便回看。
*   **作品管理**
    *   九宫格展示用户上传的视频作品。

## 4. API 接口需求 (API Requirements)

前端需对接以下 RESTful 接口 (已在 `src/services/api.ts` 中定义)：

### Auth
- `POST /auth/send_code`: 发送验证码
- `POST /auth/login_by_phone`: 手机号登录

### Upload
- `POST /upload/init`: 初始化上传 (返回 upload_id)
- `PUT /upload/chunk`: 上传分片 (Binary Body)
- `POST /upload/complete`: 合并分片

### Learning
- `POST /learn/heartbeat`: 发送心跳 (进度同步)
- `POST /learn/complete`: 标记学习状态 (learned/review_needed)

### Data
- `GET /user/me`: 获取当前用户信息
- `GET /feed/recommend`: 获取首页推荐流
- `GET /video/:id`: 获取视频详情

## 5. 非功能性需求 (Non-Functional Requirements)

1.  **移动端适配**:
    *   必须禁用视口缩放 (`user-scalable=no`)。
    *   适配刘海屏 (`safe-area-inset`)。
    *   触摸目标区域适中，符合手指点击习惯。
2.  **性能优化**:
    *   视频列表需实现虚拟滚动或懒加载 (Lazy Load)，防止 DOM 节点过多。
    *   图片使用 CDN 缩略图，非必要不加载原图。
3.  **可靠性**:
    *   弱网环境下上传必须稳定，不能因为网络抖动导致从头重传。
